# Update llms.txt catalogs

Do the editorial pass for the agent catalogs generated by gendoc.

## Steps

1. Run `gendoc-template/scripts/build.sh` (add `--fetch` if I say the Google
   Docs changed) and read the report from build-llms.py listing entries that
   need editorial attention.

2. For each flagged entry, read the actual source document, then edit
   `llms-meta.json` at the host root:
   - `description`: one line, <= 140 chars, written for an AI agent deciding
     whether to fetch this document. Say what questions it answers, not what
     it "covers". Plain and specific, no marketing tone. Use the entry's
     `nav_section` (taken from SUMMARY.md) as a hint, not an answer.
   - `category`: exactly one of: sales, product, pricing, technical,
     architecture, api, nodes, token, investors.
   - `optional: true` for reference material agents should fetch only when
     directly relevant. `set:` entries (doxygen source reference) are optional
     by default -- leave them that way.
   - `pinned: true` for the <= 5 whitepaper-tier documents that belong in the
     master catalog's Key Documents section.
   - `exclude: true` for anything that must not be published to agents.
     Investor/JV material defaults to exclude unless I say otherwise.
   - Remove `stale: true` once the description is verified against the new
     content.

3. Re-run build.sh and confirm build-llms.py reports clean.

4. Read the generated `site/llms.txt` and each `site/llms-*.txt` top to bottom
   as an external agent seeing this project for the first time. Fix anything
   misleading, redundant, or off-tone -- by editing llms-meta.json and
   regenerating, never by editing the generated files.

5. Show me a summary of what changed plus `git diff -- llms-meta.json`.
   Do not commit -- I review and commit myself.

## Rules

- Never edit files under `site/` -- everything there is generated.
- Never invent facts -- descriptions come only from what the source documents
  actually say.
- If two documents contradict each other, tell me instead of smoothing it
  over in a description.
